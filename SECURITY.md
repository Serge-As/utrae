# Security
No production credentials, private source, real financial data, private schemas, internal documentation or build archives belong in this public repository.
Use a private channel with the maintainer to disclose a suspected security exposure, and rotate compromised credentials.

Mandatory policy: [AGENTS.md](AGENTS.md) and [repository confidentiality and efficiency procedure](docs/REPOSITORY-EFFICIENCY.md). Check the staged tree and every new commit before pushing; CI alone runs too late to prevent initial disclosure. Public workflows must never obtain private repository access, data or artifacts. Detection is supplementary to content review and cannot guarantee the absence of confidential information.
